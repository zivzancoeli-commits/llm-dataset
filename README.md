# llm-dataset

Take-home zip for the from-scratch 70B smoke run.

**This repository is private.** A RunPod pod `git clone` of
`https://github.com/zivzancoeli-commits/llm-dataset.git` will 404 until you
change visibility to **Public** (Settings → Change repository visibility)
or put a `GITHUB_TOKEN` on the pod.

## File

- `scratch70b_1m_takehome 2.zip` (917,294 bytes)
  Same bytes as `scratch70b_1m_takehome.zip` in the training stack
  (git blob `1dc40a6f5cae28283fdd03a67344904f3c758b83`).
  The space in the filename is macOS's duplicate-download name.

## Training code (separate public repo)

https://github.com/zivzancoeli-commits/llm-training-stack

That clone already has the unzipped corpus. The zip here is the take-home
